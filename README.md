# Berke & Guoda

A warm, nostalgic autumn design and film journal for Berke & Guoda.

Live site: https://berkekuruoglu.github.io/berkeandguoda/

The site is published from the root of the default branch with GitHub Pages. Add films in `movies.json` with a poster in `assets/movies/`, a 0–5 Berke rating, and a 0–5 Guoda rating or `null` when she has not rated it yet. The initial film posters and Berke ratings came from his public Letterboxd profile: https://letterboxd.com/berkekuruoglu/
